## 圖片存放規則

- 以下規則有含糊部分, 作者有最終決定權
- 本資料夾只能放去背過後的高品質貼圖
- 本資料夾包含貼圖原圖, 以及放大後的貼圖
- 貼圖必須是以插腰姿勢為基礎, 風格必須一致, 不要有腳, 圖底部也不要有透明像素 (腰斬), 人物放中心側看鏡頭, 盡量填滿畫面
- 去被要去乾淨, 盡量不要有白邊跟鋸齒
- 格式必須為png

## 命名規則

若有頻道貼圖名稱以頻道貼圖為主
- 原圖命名規則: [頻道貼圖名稱].png

若沒有頻道貼圖名稱, 為了省長度, 把頻道名稱的數字拿掉, 全部小寫底線分隔, 如果是沒有後綴則以數字流水號命名, 從01開始
- roger9527的貼圖命名規則: roger_01.png

可以把貼圖亞種的動作名/或形容詞放在底線後面
- 女僕裝造型的發仔貼圖命名規則: eason_maid.png


## 好用載圖工具

使用image downloader免費下載大圖 (最大的圖要等10秒才會出現) https://chromewebstore.google.com/detail/image-downloader-picture/

## 如何去背

- https://www.remove.bg/upload 免費去背網站, 上傳貼圖點Edit in Canva
- image downloader下載

## 如何生成放大twitch_emotes

- https://twitchemotes.com/channels 上貼上頻道名稱, 找到貼圖
- copy貼圖到clipboard貼到繪圖軟體存成png
- https://www.canva.com/features/image-upscaler/ 用這個放大貼圖
- image downloader下載
