# 架構
- 本素材蒐集親親獸的亞種

```
kisskiss_HD/
├── 720_body/vt # vt 親親獸全身圖720x720
├── GIF/
└── PNG/
    ├── anime/  # 放動畫圖片
    ├── celebrity/  # 放真人明星照片
    ├── twitch_emotes/  # 放 Twitch 表情符號
    └── twitch_non_emoted/  # 放非表情符號的 Twitch 圖片
```
### 任何生成亞種都需要以這張圖的風格/姿勢為基礎
